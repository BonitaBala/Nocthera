\# 🌙 Nocthera v1.1.0



> \*\*Discord Management Bot\*\*



Nocthera is a high-performance Discord bot focused on \*\*security, moderation, automation, AI assistance, verification, embeds, and server management\*\*. It is designed to be modular, scalable, and production-ready.

\## 🔊 Join-to-Create Voice

\- Select a creator voice channel from `/setup`.
\- Members are moved into their own temporary voice channel.
\- Personal channels are deleted automatically when empty.
\- Created-channel ownership is persisted for restart recovery.
\- Generated Join-to-Create channel activity is excluded from moderation/server logs.
